Maggy zieht in deine agy-Statuszeile ein.

Ein animiertes Terminal-Maskottchen und eine eigene Statuszeile für Antigravity CLI (agy). Maggy tanzt, während agy arbeitet, stampft bei Tool-Aufrufen und nickt ein, wenn du kurz weg bist – direkt neben aktivem Modell, Kontextfenster, Kontingentbalken, Reasoning-Stufe und Git-Branch.

brew install agy-pet/tap/maggy && maggy setup

macOS oder Linux, Python 3, ein Truecolor-Terminal. Weitere Installationswege

Passe deine agy-Statuszeile an

So sieht die Statuszeile aus, die agy unter deinem Prompt anzeigt. Maggy sitzt links neben Modell, Kontextverbrauch, farbigen Kontingentbalken, Workspace und Git-Branch – jedes Frame ist exakt gleich breit, sodass nichts daneben verrutscht. Probier unten eine Einstellung aus, um direkt den passenden Befehl zu sehen.

agy~/code/my-app
> refactor the auth middleware and add tests
maggy name --reset
maggy theme auto
maggy mood on
maggy blink on

auto wählt saisonale Looks automatisch nach Datum (siehe Themes unten). Das Blinken im Leerlauf nutzt das Blink-Attribut des Terminals – so leuchten die Sternchen weiter, auch wenn agy nichts neu zeichnet.

Saisonale & eigene Themes

Standardmäßig kleidet auto Maggy an Feiertagen passend ein und wechselt am nächsten Tag zurück. Klicke auf eine Karte für die Live-Vorschau, fixiere ein Theme mit maggy theme <name> oder füge dein eigenes JSON-Theme hinzu.

Eigenes Theme erstellen

Lege eine JSON-Datei in ~/.config/maggy/themes/ ab – der Dateiname wird zum Theme-Namen (z. B. paddy.json → maggy theme paddy). Färbe Bereiche oder Zellen um, tausche die Symbole, zeichne mit prop deine eigene Deko neben Maggy (wie den Baum oder die Laterne) oder starte mit base von einem eingebauten Theme. Setze dates für auto; mit maggy theme list siehst du alle Themes.

~/.config/maggy/themes/paddy.json
{
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

Maggy für Antigravity CLI installieren

maggy setup trägt Maggy als statusLine in ~/.gemini/antigravity-cli/settings.json ein. Alle anderen Einstellungen bleiben unverändert, und die alte Datei wird als settings.json.bak gesichert.

  1. Mit Homebrew installieren
    brew install agy-pet/tap/maggy
  2. Maggy mit agy verbinden
    maggy setup
  3. Starte agy neu oder führe darin /statusline enable aus.

Aktualisieren mit brew upgrade maggy. Shell-Vervollständigungen für bash, zsh und fish sind enthalten.

  1. Starte das Installationsskript: Es klont nach ~/.maggy, verlinkt maggy nach ~/.local/bin und führt maggy setup aus.
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. Starte agy neu oder führe darin /statusline enable aus.

Optionen übergibst du per | bash -s -- --theme xmas --no-mood; spätere Updates laufen über maggy update.

  1. Repository klonen
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. Maggy mit agy verbinden
    ~/.maggy/bin/maggy setup
  3. Starte agy neu oder führe darin /statusline enable aus.

CLI-Befehle

Alles läuft über einen einzigen Befehl. Führe maggy help für die vollständige Liste aus.

maggy status
Zeigt, ob Maggy eingebunden ist, dein Theme, deine Einstellungen und eine Vorschau.
maggy preview idle
Spielt beliebige agent_state-Zustände direkt im Terminal ab, ohne den Agenten zu starten.
maggy statusline off
Blendet die Statuszeile aus, ohne sie zu entfernen. statusline on holt sie zurück.
maggy pet off
Blendet das Logo aus und behält die Metriken. motion off hält stattdessen eine feste Pose und side right setzt sie nach rechts. Alles unterstützt toggle.
maggy statusline hide git effort
Blendet einzelne Segmente aus: model, context, quota, workspace, git, effort. maggy statusline show blendet sie wieder ein.
maggy doctor
Prüft Python, Truecolor-Unterstützung, die Einstellungsdatei und die Renderzeit pro Frame.
maggy config
Zeigt ~/.config/maggy/config.json. Mit get, set oder reset anpassen.
maggy uninstall --purge
Entfernt den statusLine-Eintrag samt Konfiguration und Cache. Alle anderen agy-Einstellungen bleiben unberührt.
