Maggy 🌋 s'installe dans votre statusline agy.

Une mascotte animée de terminal et barre d'état sur mesure pour Antigravity CLI (agy). Maggy danse pendant qu'agy réfléchit, trépigne lors des appels d'outils et pique du nez quand vous vous absentez — juste à côté du modèle actif, de la fenêtre de contexte, des barres de quota, du niveau de raisonnement et de votre branche git.

brew install agy-pet/tap/maggy && maggy setup

macOS ou Linux, Python 3, un terminal truecolor. Autres méthodes d'installation

Personnalisez votre statusline agy

Voici la barre d'état qu'agy affiche sous votre invite. Maggy se tient à gauche du modèle, de l'usage du contexte, des barres de quota colorées, de l'espace de travail et de la branche git : chaque frame a exactement la même largeur, rien ne bouge autour d'elle. Modifiez une option ci-dessous pour voir la commande correspondante.

agy~/code/my-app
> refactor the auth middleware and add tests
maggy name --reset
maggy theme auto
maggy mood on
maggy blink on

Thèmes saisonniers & personnalisés

Par défaut, auto habille Maggy pour les fêtes et revient à la normale le lendemain. Cliquez sur une carte pour l'essayer en direct, fixez un thème avec maggy theme <name> ou ajoutez votre propre fichier JSON.

Créez votre propre thème

Déposez un fichier JSON dans ~/.config/maggy/themes/ : son nom devient celui du thème (ex. paddy.json → maggy theme paddy). Recolorez des zones ou des cellules, changez les étincelles, dessinez votre propre prop à côté de Maggy (comme le sapin ou la lanterne) ou partez d'un thème intégré avec base. Définissez dates pour l'activation automatique et lancez maggy theme list pour tout voir.

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

Installer Maggy pour Antigravity CLI

maggy setup fait pointer statusLine dans ~/.gemini/antigravity-cli/settings.json vers Maggy. Vos autres réglages restent intacts et l'ancien fichier est sauvegardé sous settings.json.bak.

  1. Installer via Homebrew
    brew install agy-pet/tap/maggy
  2. Connecter Maggy à agy
    maggy setup
  3. Redémarrez agy, ou lancez /statusline enable dans la session.

Mettez à jour avec brew upgrade maggy. Les complétions pour bash, zsh et fish sont incluses.

  1. Lancez l'installeur : il clone le dépôt dans ~/.maggy, crée le lien maggy dans ~/.local/bin et exécute maggy setup.
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. Redémarrez agy, ou lancez /statusline enable dans la session.

Passez des options via | bash -s -- --theme xmas --no-mood, puis mettez à jour avec maggy update.

  1. Cloner le dépôt
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. Connecter Maggy à agy
    ~/.maggy/bin/maggy setup
  3. Redémarrez agy, ou lancez /statusline enable dans la session.

Commandes CLI

Tout passe par une seule commande. Lancez maggy help pour la liste complète.

maggy status
Affiche si Maggy est bien configurée, votre thème, vos réglages et un aperçu en direct.
maggy preview idle
Joue n'importe quel agent_state dans votre terminal sans lancer de requête agent.
maggy statusline off
Masque la barre d'état sans la supprimer. statusline on la réactive.
maggy pet off
Masque le logo tout en gardant les métriques. motion off fige la pose et side right la place à droite. Chaque option accepte toggle.
maggy statusline hide git effort
Masque les segments de votre choix : model, context, quota, workspace, git, effort. maggy statusline show les réaffiche.
maggy doctor
Vérifie Python, le support truecolor, le fichier de réglages et le temps de rendu d'une frame.
maggy config
Affiche ~/.config/maggy/config.json. Utilisez get, set ou reset pour le modifier.
maggy uninstall --purge
Supprime l'entrée statusLine, la configuration et le cache sans toucher à vos autres réglages agy.

Questions fréquentes

Réponses aux questions courantes sur l'installation, la personnalisation et le dépannage de Maggy pour Antigravity CLI.

Comment afficher la fenêtre de contexte et les quotas dans Antigravity CLI (agy) ?

Installez Maggy avec brew install agy-pet/tap/maggy && maggy setup puis redémarrez agy ou lancez /statusline enable. Maggy configure statusLine dans ~/.gemini/antigravity-cli/settings.json et affiche le modèle actif, le % de contexte, les barres de quota colorées, l'espace de travail, la branche git et le niveau de raisonnement à côté de la mascotte.

Pourquoi la barre d'état ne s'affiche-t-elle pas après maggy setup ?

Redémarrez agy ou exécutez /statusline enable dans votre session. Si elle n'apparaît toujours pas, lancez maggy doctor pour vérifier Python 3, la prise en charge truecolor du terminal et l'entrée statusLine dans ~/.gemini/antigravity-cli/settings.json.

Maggy ralentit-il agy ou envoie-t-il de la télémétrie ?

Non. L'outil CLI maggy fonctionne 100 % en local avec la seule bibliothèque standard Python 3 et n'envoie aucune télémétrie. agy ne l'appelle qu'en cas de changement d'état (sans minuteur en arrière-plan), et vous pouvez mesurer la vitesse de rendu avec maggy doctor.

Puis-je masquer la mascotte ou choisir les segments affichés ?

Oui. Lancez maggy pet off pour ne garder que les métriques, maggy motion off pour une pose fixe ou maggy side right pour placer Maggy à droite. Masquez des segments avec maggy statusline hide (model, context, quota, workspace, git, effort) et restaurez-les avec maggy statusline show.

Quels systèmes et terminaux sont pris en charge ?

Maggy fonctionne sur macOS et Linux (y compris WSL) dans tout terminal truecolor (24 bits) comme Ghostty, Kitty, iTerm2, WezTerm, Alacritty, Warp ou le terminal intégré de VS Code, avec Python 3.

  1. agy ne redessine la statusline que lorsque quelque chose change, jamais à intervalle fixe. Au repos, Maggy garde une seule pose et seules ses étincelles scintillent (via l'attribut blink du terminal). Cliquez à nouveau sur idle pour simuler le prochain rafraîchissement.
  2. auto choisit la tenue de saison selon la date (voir Thèmes).
  3. Le scintillement au repos s'appuie sur l'attribut blink du terminal : les étincelles continuent même quand agy ne rafraîchit plus l'écran.
