节日与自定义主题

默认 auto 会在节日当天自动给 Maggy 换装，次日恢复原样。点击下方卡片可实时预览，用 maggy theme <name> 可随时锁定主题，也能放入 JSON 文件打造专属主题。

为 Antigravity CLI 安装 Maggy

maggy setup 会把 ~/.gemini/antigravity-cli/settings.json 中的 statusLine 指向 Maggy。其他配置不受影响，原文件会自动备份为 settings.json.bak。

  1. 通过 Homebrew 安装
    brew install agy-pet/tap/maggy
  2. 接入 agy
    maggy setup
  3. 重启 agy，或在 agy 中运行 /statusline enable。

升级只需运行 brew upgrade maggy，并自带 bash、zsh 和 fish 的命令补全。

  1. 运行一键安装脚本：自动克隆到 ~/.maggy、把 maggy 链接进 ~/.local/bin，并完成 maggy setup。
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. 重启 agy，或在 agy 中运行 /statusline enable。

可通过 | bash -s -- --theme xmas --no-mood 传入初始化参数，后续用 maggy update 更新。

  1. 克隆仓库
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. 接入 agy
    ~/.maggy/bin/maggy setup
  3. 重启 agy，或在 agy 中运行 /statusline enable。

CLI 命令

所有功能都集成在一个命令里。运行 maggy help 查看完整列表。

maggy status
查看 Maggy 的接入状态、当前主题与配置，并输出实时预览。
maggy preview idle
无需发起对话，直接在终端预览任意 agent_state 动画。
maggy statusline off
暂时隐藏状态栏但不删除配置，用 statusline on 即可恢复。
maggy pet off
隐藏宠物、只保留指标；motion off 可定格为静态姿势，side right 可移至右侧，均支持 toggle 切换。
maggy statusline hide git effort
按需隐藏状态栏模块：model、context、quota、workspace、git、effort。用 maggy statusline show 恢复。
maggy doctor
检测 Python 环境、真彩色支持、配置文件以及单帧渲染耗时。
maggy config
查看 ~/.config/maggy/config.json，支持通过 get、set 或 reset 修改。
maggy uninstall --purge
移除 statusLine 配置项、配置文件与缓存，其余 agy 设置保持原样。

打造你的专属主题

将 JSON 文件放入 ~/.config/maggy/themes/，文件名即为主题名（如 paddy.json → maggy theme paddy）。可按区域或像素格自定义配色、替换星光字符，用 prop 在 Maggy 身旁画出自己的装饰（就像圣诞树或灯笼），或用 base 基于内置主题修改。设置 dates 即可让 auto 在指定日期自动切换，运行 maggy theme list 查看全部已安装主题。

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

常见问题

关于 Antigravity CLI 状态栏工具 Maggy 的安装、自定义与故障排查。

如何在 agy 状态栏中显示用量、配额限额和重置倒计时？

运行 brew install agy-pet/tap/maggy && maggy setup 安装并配置，然后重启 agy 或在会话中执行 /statusline enable。Maggy 会接入 ~/.gemini/antigravity-cli/settings.json 中的 statusLine，实时显示当前模型、上下文占比、彩色 5 小时与每周配额限额条及重置时间倒计时（刷新间自动缓存）、工作区、Git 分支和推理强度。

运行 maggy setup 后为什么没有显示状态栏？

请重启 agy，或在当前会话中输入 /statusline enable。如果仍未显示，可运行 maggy doctor 检查 Python 3、终端真彩色支持以及 ~/.gemini/antigravity-cli/settings.json 中的 statusLine 配置。

Maggy 会拖慢 agy 或收集遥测数据吗？

不会。maggy CLI 完全在本地运行，仅依赖 Python 3 标准库，零遥测数据上报。agy 仅在状态变化时调用它（没有后台定时器），你也可以随时运行 maggy doctor 查看单帧渲染耗时。

可以隐藏吉祥物或自定义显示哪些状态栏信息吗？

可以。运行 maggy pet off 可只保留指标，maggy motion off 可固定静态姿势，maggy side right 可将 Maggy 移到右侧。使用 maggy statusline hide 隐藏指定项（model、context、quota、workspace、git、effort），用 maggy statusline show 恢复。

支持哪些系统和终端？

Maggy 支持 macOS 和 Linux（含 WSL），需安装 Python 3，并适配所有支持 24 位真彩色的终端，如 Ghostty、Kitty、iTerm2、WezTerm、Alacritty、Warp 及 VS Code 内置终端。

agy 状态栏里的宠物动画是如何工作的？

Maggy 直接在终端里绘制带表情眼睛的 Antigravity Logo，并根据 agent_state 播放不同状态的动画——working 时起舞、tool_use 时踏步、reviewing 时探头、idle 时星光闪烁、空闲 2 分钟后打瞌睡。随时可用 maggy preview working 预览动画，或用 maggy motion off 固定为静态姿势。

  1. agy 只在状态变化时重绘状态栏，不会定时刷新。空闲时 Maggy 保持当前姿势，只有周围的小星星靠终端的闪烁属性一闪一闪。再点一次 idle 可模拟下一次重绘。
  2. auto 会按日期自动切换节日装扮（详见主题）。
  3. 空闲闪烁利用终端自带的 blink 属性，就算 agy 不再刷新，小星星也会继续闪烁。
