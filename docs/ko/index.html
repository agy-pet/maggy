내 agy 상태바에 사는 Maggy 🌋

Antigravity CLI(agy)용 애니메이션 agy 펫이자 커스텀 상태바입니다. agy가 일할 땐 로고 애니메이션이 신나게 춤추고, 도구를 호출할 땐 발을 동동 구르며, 자리를 비우면 꾸벅꾸벅 좁니다. 현재 모델, 컨텍스트 사용량, 5시간·주간 쿼터 한도와 리셋 카운트다운, 추론 강도, Git 브랜치 바로 옆에서 함께합니다.

brew install agy-pet/tap/maggy && maggy setup

macOS 또는 Linux, Python 3, 트루컬러 터미널이 필요합니다. 다른 설치 방법

agy 상태바 커스터마이즈

프롬프트 아래에 agy가 띄워 주는 상태바입니다. 애니메이션 agy 펫 옆에 모델, 컨텍스트 사용량, 색상으로 구분된 5시간·주간 쿼터 한도와 리셋 타이머, 워크스페이스, Git 브랜치를 표시하며 모든 프레임 너비가 같아 흔들리지 않습니다. 아래 옵션을 바꿔 보며 해당하는 명령어를 바로 확인해 보세요.

agy~/code/my-app
> refactor the auth middleware and add tests

시즌 & 커스텀 테마

기본 auto 모드는 기념일에 맞춰 자동으로 옷을 갈아입고 다음 날 원래대로 돌아옵니다. 아래 카드를 눌러 바로 미리 보거나 maggy theme <name>으로 고정하고, 나만의 JSON 테마도 추가해 보세요.

Antigravity CLI에 Maggy 설치하기

maggy setup은 ~/.gemini/antigravity-cli/settings.json의 statusLine을 Maggy로 연결합니다. 다른 설정은 건드리지 않으며 기존 파일은 settings.json.bak으로 백업됩니다.

  1. Homebrew로 설치
    brew install agy-pet/tap/maggy
  2. agy에 연결
    maggy setup
  3. agy를 재시작하거나 세션 내에서 /statusline enable을 실행하세요.

brew upgrade maggy로 간편하게 업그레이드할 수 있습니다. bash, zsh, fish 셸 자동 완성도 함께 설치됩니다.

  1. 설치 스크립트를 실행하면 ~/.maggy에 클론하고 ~/.local/bin에 maggy를 연결한 뒤 maggy setup까지 자동으로 마칩니다.
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. agy를 재시작하거나 세션 내에서 /statusline enable을 실행하세요.

| bash -s -- --theme xmas --no-mood처럼 초기 옵션을 넘길 수 있으며, 업데이트는 maggy update로 하면 됩니다.

  1. 저장소 클론
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. agy에 연결
    ~/.maggy/bin/maggy setup
  3. agy를 재시작하거나 세션 내에서 /statusline enable을 실행하세요.

CLI 명령어

모든 기능을 하나의 명령어로 제어합니다. 전체 목록은 maggy help로 확인하세요.

maggy status
Maggy 연결 상태와 현재 테마, 설정값 그리고 미리보기를 보여줍니다.
maggy preview idle
에이전트를 돌리지 않고도 원하는 agent_state 애니메이션을 터미널에서 바로 재생합니다.
maggy statusline off
설정을 지우지 않고 상태바만 잠시 숨깁니다. statusline on으로 다시 켤 수 있습니다.
maggy pet off
로고는 숨기고 지표만 남깁니다. motion off로 움직임을 멈추고, side right로 오른쪽으로 옮길 수 있습니다. 모두 toggle을 지원합니다.
maggy statusline hide git effort
원하는 항목만 골라 숨깁니다: model, context, quota, workspace, git, effort. maggy statusline show로 다시 띄울 수 있습니다.
maggy doctor
Python, 트루컬러 지원, 설정 파일 상태 및 프레임 렌더링 속도를 점검합니다.
maggy config
~/.config/maggy/config.json을 보여줍니다. get, set, reset으로 바꿀 수 있습니다.
maggy uninstall --purge
statusLine 항목과 설정 파일, 캐시를 깔끔하게 지웁니다. 다른 agy 설정은 그대로 유지됩니다.

나만의 테마 만들기

~/.config/maggy/themes/에 JSON 파일을 넣으면 파일명이 곧 테마 이름이 됩니다(예: paddy.json → maggy theme paddy). 영역이나 셀 색상과 반짝이 문자를 바꾸고, prop으로 Maggy 옆에 트리나 등불 같은 장식을 직접 그리거나, base로 기본 테마를 바탕으로 수정할 수 있습니다. dates를 지정하면 auto로 자동 적용되며, maggy theme list로 전체 테마를 확인하세요.

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

자주 묻는 질문

Antigravity CLI 상태바 도구 Maggy의 설치, 커스터마이징 및 문제 해결 안내입니다.

agy 상태바에서 사용량, 쿼터 한도, 리셋 카운트다운을 표시하려면 어떻게 하나요?

brew install agy-pet/tap/maggy && maggy setup으로 설치한 뒤 agy를 재시작하거나 /statusline enable을 실행하세요. ~/.gemini/antigravity-cli/settings.json의 statusLine에 연결되어 현재 모델, 컨텍스트 사용률, 색상으로 구분된 5시간·주간 쿼터 한도 바와 리셋 시각·카운트다운(새로고침 시에도 캐시 유지), 워크스페이스, Git 브랜치, 추론 강도가 표시됩니다.

maggy setup 후에도 상태바가 보이지 않아요.

agy를 재시작하거나 활성 세션에서 /statusline enable을 실행해 보세요. 그래도 보이지 않으면 maggy doctor를 실행해 Python 3, 트루컬러 터미널 지원 여부, ~/.gemini/antigravity-cli/settings.json의 statusLine 항목을 확인하세요.

Maggy가 agy를 느리게 하거나 텔레메트리를 전송하나요?

아니요. maggy CLI는 Python 3 표준 라이브러리만으로 100% 로컬에서 실행되며 어떠한 텔레메트리도 전송하지 않습니다. agy가 상태 변경 시에만 호출(백그라운드 타이머 없음)하며, maggy doctor로 언제든 렌더링 속도를 확인할 수 있습니다.

펫을 숨기거나 표시할 상태바 항목을 선택할 수 있나요?

네. maggy pet off로 지표만 남기거나, maggy motion off로 정지 포즈를 유지하고, maggy side right로 오른쪽으로 옮길 수 있습니다. maggy statusline hide로 항목(model, context, quota, workspace, git, effort)을 숨기고 maggy statusline show로 복원하세요.

어떤 플랫폼과 터미널을 지원하나요?

Python 3가 설치된 macOS 및 Linux(WSL 포함)에서 동작하며 Ghostty, Kitty, iTerm2, WezTerm, Alacritty, Warp, VS Code 통합 터미널 등 모든 24비트 트루컬러 터미널을 지원합니다.

상태바의 agy 펫 애니메이션은 어떻게 동작하나요?

Maggy는 표정이 살아있는 눈이 달린 Antigravity 로고를 터미널에 직접 그려 agent_state에 따라 애니메이션을 재생합니다. working 중엔 춤추고, tool_use 중엔 발을 구르며, reviewing엔 기웃거리고, idle엔 반짝이다 2분 후 좁니다. maggy preview working으로 미리 보거나 maggy motion off로 정지할 수 있습니다.

Homebrew가 이전 버전의 Maggy를 설치하는 이유는 무엇인가요?

Maggy를 삭제해도 Homebrew의 로컬 탭은 남아 있습니다. 탭이 오래되면 다시 설치할 때 이전 버전이 선택될 수 있습니다. 아래 명령으로 Maggy 탭만 갱신하고 최신 버전을 설치하세요. 설치된 버전은 maggy --version으로 확인할 수 있습니다.

HOMEBREW_NO_AUTO_UPDATE=1 brew tap agy-pet/tap && git -C "$(brew --repo agy-pet/tap)" pull --ff-only && HOMEBREW_NO_AUTO_UPDATE=1 brew install agy-pet/tap/maggy && maggy setup
  1. agy는 상태가 바뀔 때만 상태바를 다시 그리며 타이머로 갱신하지 않습니다. 대기 상태에서는 Maggy가 한 자세를 유지하고, 터미널의 blink 속성으로 반짝이만 깜박입니다. idle을 한 번 더 누르면 다음 화면 갱신을 미리 볼 수 있습니다.
  2. auto는 날짜에 따라 시즌 테마를 자동으로 바꿉니다(테마 참고).
  3. 대기 중 깜박임은 터미널의 blink 속성을 사용하므로 agy가 화면을 다시 그리지 않아도 별빛이 계속 반짝입니다.

Antigravity CLI용 비공식 상태바 프로젝트입니다. Google과는 관련이 없습니다.
