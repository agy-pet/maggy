agy ステータスラインに住む Maggy 🌋

Antigravity CLI（agy）向けのアニメーション付きターミナルペット＆カスタムステータスライン。agy が動いている間は楽しそうに踊り、ツール実行中は元気よく足踏みし、席を外すとうとうと居眠りします。使用中のモデル、コンテキスト使用率、クォータ残量バー、推論レベル、Git ブランチのすぐ隣でいつも一緒です。

brew install agy-pet/tap/maggy && maggy setup

macOS / Linux・Python 3・Truecolor 対応ターミナルが必要です。その他のインストール方法

agy ステータスラインをカスタマイズ

プロンプトの下に agy が表示するステータスラインです。モデル、コンテキスト使用率、色分けされたクォータバー、ワークスペース、Git ブランチの左側に Maggy が並びます。全フレーム同じ幅なので、横の表示がガタつくことはありません。下の設定を変えると、対応するコマンドがリアルタイムで確認できます。

agy~/code/my-app
> refactor the auth middleware and add tests
maggy name --reset
maggy theme auto
maggy mood on
maggy blink on

季節テーマ＆カスタムテーマ

デフォルトの auto はイベント当日に自動で衣替えし、翌日には元に戻ります。下のカードをクリックするとライブプレビューでき、maggy theme <name> で固定したり、独自の JSON テーマを追加したりできます。

オリジナルテーマを作る

~/.config/maggy/themes/ に JSON ファイルを置くだけで、ファイル名がそのままテーマ名になります（例：paddy.json → maggy theme paddy）。パーツやセル単位で配色を変えたり、きらめき記号を差し替えたり、prop で Maggy の横にツリーや提灯のような飾りを描いたり、base で組み込みテーマをベースにしたりできます。dates を設定すれば auto で自動表示。maggy theme list で一覧を確認できます。

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

Antigravity CLI に Maggy をインストール

maggy setup は ~/.gemini/antigravity-cli/settings.json の statusLine に Maggy を設定します。他の設定には触れず、元のファイルは settings.json.bak としてバックアップされます。

  1. Homebrew でインストール
    brew install agy-pet/tap/maggy
  2. agy に組み込む
    maggy setup
  3. agy を再起動するか、セッション内で /statusline enable を実行してください。

brew upgrade maggy でアップデートできます。bash・zsh・fish のシェル補完も同梱されています。

  1. インストーラーを実行します。~/.maggy にクローンし、~/.local/bin に maggy をリンクして maggy setup まで自動で行います。
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. agy を再起動するか、セッション内で /statusline enable を実行してください。

| bash -s -- --theme xmas --no-mood のように初期オプションを渡せます。更新は maggy update で行えます。

  1. リポジトリをクローン
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. agy に組み込む
    ~/.maggy/bin/maggy setup
  3. agy を再起動するか、セッション内で /statusline enable を実行してください。

CLI コマンド

操作はすべて 1 つのコマンドで完結します。全一覧は maggy help を実行してください。

maggy status
Maggy の連携状態やテーマ・設定を確認し、プレビューを表示します。
maggy preview idle
エージェントを実行せずに、好きな agent_state の動きをターミナルで再生します。
maggy statusline off
設定を残したままステータスラインを一時非表示にします。statusline on で復帰できます。
maggy pet off
ロゴを隠してメトリクスだけ表示します。motion off で静止ポーズに、side right で右側配置に切り替え可能。いずれも toggle に対応しています。
maggy statusline hide git effort
表示項目を絞り込みます（model / context / quota / workspace / git / effort）。maggy statusline show で戻せます。
maggy doctor
Python、Truecolor 対応、設定ファイル、および 1 フレームあたりの描画速度を診断します。
maggy config
~/.config/maggy/config.json を表示します。get・set・reset で編集できます。
maggy uninstall --purge
statusLine の設定・設定ファイル・キャッシュを削除します。他の agy 設定には触れません。

よくある質問

Antigravity CLI 向けステータスライン Maggy のインストール・カスタマイズ・トラブルシューティング。

Antigravity CLI (agy) でコンテキスト使用率やクォータ残量バーを表示するには？

brew install agy-pet/tap/maggy && maggy setup でインストール後、agy を再起動するか /statusline enable を実行してください。~/.gemini/antigravity-cli/settings.json の statusLine に登録され、マスコットの横にモデル、コンテキスト使用率、色分けされたクォータバー、ワークスペース、Git ブランチ、推論レベルが表示されます。

maggy setup 後にステータスラインが表示されない場合は？

agy を再起動するか、セッション内で /statusline enable を実行してください。それでも表示されない場合は maggy doctor を実行し、Python 3・トゥルーカラー対応・~/.gemini/antigravity-cli/settings.json の statusLine 設定を確認してください。

Maggy は agy の動作を重くしたり、テレメトリを送信したりしますか？

いいえ。maggy CLI は Python 3 標準ライブラリのみで完全ローカル動作し、テレメトリは一切送信しません。agy が状態変化時のみ呼び出す仕組み（バックグラウンドタイマーなし）で、描画速度はいつでも maggy doctor で計測できます。

マスコットを非表示にしたり、表示する項目をカスタマイズできますか？

はい。maggy pet off でメトリクスのみ表示、maggy motion off で静止表示、maggy side right で右側配置に変更できます。maggy statusline hide で個別項目（model・context・quota・workspace・git・effort）を隠し、maggy statusline show で戻せます。

対応している OS とターミナルは？

Python 3 が動作する macOS および Linux（WSL を含む）に対応しています。Ghostty、Kitty、iTerm2、WezTerm、Alacritty、Warp、VS Code 統合ターミナルなど、24-bit トゥルーカラー対応のターミナルで利用できます。

  1. agy は状態が変わったときだけステータスラインを再描画し、タイマーでは更新しません。アイドル中の Maggy は同じポーズのままで、周りのきらめきだけがターミナルの点滅機能（blink）で光ります。idle をもう一度クリックすると次の再描画を再現できます。
  2. auto は日付に合わせて季節テーマを自動で切り替えます（詳しくはテーマを参照）。
  3. アイドル時の点滅はターミナルの blink 属性を使うため、agy の再描画が止まっても星が光り続けます。
