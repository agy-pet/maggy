Install Maggy for Antigravity CLI

maggy setup points statusLine in ~/.gemini/antigravity-cli/settings.json at Maggy. Your other settings stay as they are, and the old file is saved as settings.json.bak.

  1. Install the formula
    brew install agy-pet/tap/maggy
  2. Hook Maggy into agy
    maggy setup
  3. Restart agy, or run /statusline enable inside it.

Upgrade with brew upgrade maggy. Shell completions for bash, zsh and fish come with it.

  1. Run the installer. It clones to ~/.maggy, links maggy into ~/.local/bin and runs maggy setup.
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. Restart agy, or run /statusline enable inside it.

Pass setup options with | bash -s -- --theme xmas --no-mood. Update later with maggy update.

    git clone https://github.com/agy-pet/maggy.git ~/.maggy

  3. Restart agy, or run /statusline enable inside it.

CLI commands

Everything goes through one command. Run maggy help for the full list.

maggy status
Shows whether Maggy is hooked up, your theme and settings, and a sample of her.
maggy preview idle
Plays any agent_state in your terminal without starting an agent turn.
maggy statusline off
Hides the statusline without removing it. statusline on brings it back.
maggy pet off
Hides the logo and keeps the metrics. motion off holds a still pose instead, and side right moves her to the right. Each takes toggle.
maggy statusline hide git effort
Leaves segments out: model, context, quota, workspace, git, effort. maggy statusline show brings them back.
maggy doctor
Checks Python, truecolor support, the settings file, and how fast a frame renders.
maggy config
Shows ~/.config/maggy/config.json. Use get, set or reset to change it.
maggy uninstall --purge
Removes the statusLine entry, config and cache. Your other agy settings stay.

Make your own theme

Drop a JSON file into ~/.config/maggy/themes/ and its filename becomes the theme name (e.g. paddy.json → maggy theme paddy). Recolor regions or cells, swap sparkles, draw your own prop beside Maggy (like the tree or lantern), or start from a built-in look with base. Set dates so auto activates it automatically, and run maggy theme list to see all installed themes.

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

Frequently asked questions

Common questions about installing, customizing, and troubleshooting the Maggy statusline for Antigravity CLI.

How do I show usage, quota limits, and reset countdowns in the agy statusline?

Install Maggy with brew install agy-pet/tap/maggy && maggy setup and restart agy or run /statusline enable. Maggy hooks into statusLine in ~/.gemini/antigravity-cli/settings.json and displays your live model, context window usage %, color-coded 5-hour and weekly quota limit bars with reset times and countdowns (cached across refreshes), workspace, git branch, and reasoning effort.

Why isn't the statusline showing after maggy setup?

Restart agy or run /statusline enable inside an active session. If it still doesn't appear, run maggy doctor to verify Python 3, truecolor terminal support, and the statusLine entry in ~/.gemini/antigravity-cli/settings.json.

Does Maggy slow down agy or send any telemetry?

No. The maggy CLI runs 100% locally using only the Python 3 standard library and sends zero telemetry. agy only invokes it when state changes (never on a background timer), and you can check render speed anytime with maggy doctor.

Can I hide the mascot or customize which statusline segments appear?

Yes. Run maggy pet off to keep only the metrics, maggy motion off for a still pose, or maggy side right to move Maggy to the right. Hide individual segments with maggy statusline hide (model, context, quota, workspace, git, effort) and restore them with maggy statusline show.

What platforms and terminals are supported?

Maggy works on macOS and Linux (including WSL) in any truecolor (24-bit) terminal such as Ghostty, Kitty, iTerm2, WezTerm, Alacritty, Warp, or VS Code's integrated terminal, and requires Python 3.

How does the agy pet animation work in the statusline?

Maggy renders the Antigravity logo with expressive eyes directly in your terminal and steps through state-aware animations driven by agent_state — dancing while working, stomping during tool_use, leaning while reviewing, twinkling while idle, and dozing after 2 minutes. Preview any animation anytime with maggy preview working, or freeze it with maggy motion off.

  1. agy redraws the statusline only when something changes, never on a timer. While idle Maggy holds one pose and only her sparkles twinkle (via the terminal's blink attribute). Click idle again to simulate the next redraw.
  2. auto picks seasonal looks by date (see Themes).
  3. Idle twinkle uses the terminal's blink attribute, so sparkles keep moving even when agy stops redrawing.
