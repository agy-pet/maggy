A Maggy mora na sua statusline do agy.

Uma mascote animada de terminal e barra de status sob medida para a Antigravity CLI (agy). A Maggy dança enquanto o agy trabalha, sapateia nas chamadas de ferramentas e tira um cochilo quando você se afasta — bem ao lado do modelo atual, janela de contexto, barras de cota, nível de raciocínio e branch do git.

brew install agy-pet/tap/maggy && maggy setup

macOS ou Linux, Python 3 e um terminal truecolor. Outras formas de instalar

Personalize sua statusline do agy

Esta é a barra de status que o agy desenha abaixo do seu prompt. A Maggy fica à esquerda do modelo, uso de contexto, barras de cota coloridas, workspace e branch do git — todos os quadros têm exatamente a mesma largura, então nada ao lado dela sai do lugar. Teste uma opção abaixo para ver o comando correspondente.

agy~/code/my-app
> refactor the auth middleware and add tests
maggy name --reset
maggy theme auto
maggy mood on
maggy blink on

auto escolhe visuais sazonais pela data (veja Temas abaixo). O brilho em repouso usa o atributo blink do terminal, mantendo os brilhos piscando mesmo quando o agy para de redesenhar.

Temas sazonais e personalizados

Por padrão, auto veste a Maggy em datas festivas e volta ao normal no dia seguinte. Clique em um cartão para testar ao vivo, fixe um tema com maggy theme <name> ou adicione seu próprio tema em JSON.

Crie seu próprio tema

Coloque um arquivo JSON em ~/.config/maggy/themes/ e o nome do arquivo vira o nome do tema (ex.: paddy.json → maggy theme paddy). Personalize cores por região ou célula, troque os brilhos, desenhe seu próprio prop ao lado da Maggy (como a árvore ou a lanterna) ou parta de um tema embutido com base. Defina dates para o auto ativar sozinho e rode maggy theme list para ver todos.

~/.config/maggy/themes/paddy.json
{
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

Instale a Maggy para Antigravity CLI

maggy setup aponta statusLine em ~/.gemini/antigravity-cli/settings.json para a Maggy. Suas outras configurações permanecem intactas e o arquivo antigo é salvo como settings.json.bak.

  1. Instale via Homebrew
    brew install agy-pet/tap/maggy
  2. Conecte a Maggy ao agy
    maggy setup
  3. Reinicie o agy ou execute /statusline enable na sessão.

Atualize com brew upgrade maggy. Inclui autocompletar para bash, zsh e fish.

  1. Execute o instalador: ele clona para ~/.maggy, cria o link de maggy em ~/.local/bin e roda o maggy setup.
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. Reinicie o agy ou execute /statusline enable na sessão.

Passe opções com | bash -s -- --theme xmas --no-mood e atualize depois com maggy update.

  1. Clone o repositório
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. Conecte a Maggy ao agy
    ~/.maggy/bin/maggy setup
  3. Reinicie o agy ou execute /statusline enable na sessão.

Comandos CLI

Tudo passa por um único comando. Execute maggy help para ver a lista completa.

maggy status
Mostra se a Maggy está configurada, seu tema, suas opções e uma prévia ao vivo.
maggy preview idle
Reproduz qualquer agent_state no terminal sem precisar iniciar um turno do agente.
maggy statusline off
Oculta a barra de status sem removê-la. statusline on a traz de volta.
maggy pet off
Oculta o logotipo mantendo as métricas. motion off mantém uma pose estática e side right a move para a direita. Cada um aceita toggle.
maggy statusline hide git effort
Oculta os segmentos que quiser: model, context, quota, workspace, git, effort. maggy statusline show restaura.
maggy doctor
Verifica Python, suporte a truecolor, o arquivo de configuração e o tempo de renderização de um quadro.
maggy config
Mostra ~/.config/maggy/config.json. Use get, set ou reset para alterar.
maggy uninstall --purge
Remove a entrada statusLine, a configuração e o cache. Suas outras configurações do agy ficam intactas.
