讓 Maggy 🌋 住進你的 agy 狀態列

專為 Antigravity CLI（agy）打造的動態 agy 寵物與自訂狀態列。agy 運作時 Maggy 的 Logo 動畫會跟著起舞，呼叫工具時輕快踏步，你離開一下她就會打瞌睡——緊鄰你的目前模型、上下文用量、5 小時與每週配額上限及重設倒數、推論強度與 Git 分支。

brew install agy-pet/tap/maggy && maggy setup

需要 macOS 或 Linux、Python 3 及支援真彩色的終端機。其他安裝方式

agent_state腳註 1

自訂你的 agy 狀態列

這就是 agy 顯示在提示字元下方的狀態列：在動態 agy 寵物旁即時呈現模型、上下文用量、彩色 5 小時與每週配額上限及重設倒數、工作區與 Git 分支——每個影格都嚴格等寬，右側資訊完全不會晃動。調整下方的選項，就能即時看到對應指令。

agy~/code/my-app
> refactor the auth middleware and add tests

maggy name --reset
腳註 2
maggy theme auto
maggy mood on
腳註 3
maggy blink on

節慶與自訂主題

預設的 auto 會在節日當天自動幫 Maggy 換裝，隔天恢復原樣。點選下方卡片就能即時預覽，用 maggy theme <name> 可隨時鎖定主題，也能放入 JSON 檔案打造專屬主題。

為 Antigravity CLI 安裝 Maggy

maggy setup 會將 ~/.gemini/antigravity-cli/settings.json 中的 statusLine 指向 Maggy。其他設定不受影響，原檔案會自動備份為 settings.json.bak。

  1. 透過 Homebrew 安裝
    brew install agy-pet/tap/maggy
  2. 串接至 agy
    maggy setup
  3. 重新啟動 agy，或在 agy 中執行 /statusline enable。

升級只需執行 brew upgrade maggy，並內建 bash、zsh 與 fish 的指令自動補齊。

  1. 執行安裝腳本：自動 clone 到 ~/.maggy、將 maggy 連結至 ~/.local/bin，並完成 maggy setup。
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. 重新啟動 agy，或在 agy 中執行 /statusline enable。

可透過 | bash -s -- --theme xmas --no-mood 傳入初始選項，日後用 maggy update 更新。

  1. Clone 儲存庫
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. 串接至 agy
    ~/.maggy/bin/maggy setup
  3. 重新啟動 agy，或在 agy 中執行 /statusline enable。

CLI 指令

所有功能都整合在同一個指令中。執行 maggy help 查看完整清單。

maggy status
查看 Maggy 的整合狀態、目前主題與設定，並顯示即時預覽。
maggy preview idle
不必開啟對話，直接在終端機預覽任意 agent_state 動畫。
maggy statusline off
暫時隱藏狀態列但不移除設定，用 statusline on 即可恢復。
maggy pet off
隱藏寵物、僅保留指標；motion off 可定格為靜態姿勢，side right 可移至右側，皆支援 toggle 切換。
maggy statusline hide git effort
選擇要隱藏的狀態列項目：model、context、quota、workspace、git、effort。用 maggy statusline show 恢復。
maggy doctor
檢查 Python 環境、真彩色支援、設定檔以及單一影格的繪製耗時。
maggy config
查看 ~/.config/maggy/config.json，支援透過 get、set 或 reset 修改。
maggy uninstall --purge
移除 statusLine 項目、設定檔與快取，不影響其他 agy 設定。

打造你的專屬主題

將 JSON 檔案放入 ~/.config/maggy/themes/，檔名即為主題名稱（例如 paddy.json → maggy theme paddy）。可依區域或像素格自訂配色、替換星光字元，用 prop 在 Maggy 身旁畫出自己的裝飾（就像聖誕樹或燈籠），或用 base 以內建主題為基礎修改。設定 dates 即可讓 auto 在指定日期自動套用，執行 maggy theme list 查看所有已安裝的主題。

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

常見問題

關於 Antigravity CLI 狀態列工具 Maggy 的安裝、自訂與疑難排解。

如何在 agy 狀態列中顯示用量、配額上限與重設倒數？

執行 brew install agy-pet/tap/maggy && maggy setup 完成安裝與設定，接著重啟 agy 或在工作階段中輸入 /statusline enable。Maggy 會掛載至 ~/.gemini/antigravity-cli/settings.json 的 statusLine，即時顯示目前模型、上下文使用率、彩色 5 小時與每週配額上限條及重設時間倒數（重繪間自動快取）、工作區、Git 分支與推理強度。

執行 maggy setup 後為什麼沒有出現狀態列？

請重啟 agy，或在目前工作階段中執行 /statusline enable。若仍未顯示，請執行 maggy doctor 檢查 Python 3、終端機全彩支援以及 ~/.gemini/antigravity-cli/settings.json 中的 statusLine 設定。

Maggy 會拖慢 agy 或傳送遙測資料嗎？

不會。maggy CLI 完全在本地執行，僅使用 Python 3 標準函式庫，完全不傳送任何遙測資料。agy 只在狀態變更時呼叫它（無背景計時器），你隨時可用 maggy doctor 檢查單格渲染速度。

可以隱藏吉祥物或自訂要顯示的狀態列區段嗎？

可以。執行 maggy pet off 只保留指標，maggy motion off 保持靜態姿勢，maggy side right 將 Maggy 移至右側。可用 maggy statusline hide 隱藏個別區段（model、context、quota、workspace、git、effort），並以 maggy statusline show 恢復。

支援哪些平台與終端機？

Maggy 支援 macOS 與 Linux（包含 WSL），需要 Python 3，適用於所有 24-bit 全彩終端機，例如 Ghostty、Kitty、iTerm2、WezTerm、Alacritty、Warp 與 VS Code 內建終端機。

agy 狀態列中的寵物動畫是如何運作的？

Maggy 直接在終端機繪製帶有表情雙眼的 Antigravity Logo，並依 agent_state 切換狀態動畫——working 時跳舞、tool_use 時踏步、reviewing 時探頭、idle 時星光閃爍、閒置 2 分鐘後打瞌睡。隨時可用 maggy preview working 預覽動畫，或用 maggy motion off 固定靜態姿勢。

  1. agy 只在狀態變化時才重繪狀態列，不會定時更新。閒置時 Maggy 會維持同一個姿勢，只有周圍的小星星透過終端機的閃爍屬性一閃一閃。再點一次 idle 可模擬下一次重繪。
  2. auto 會依日期自動切換節慶裝扮（詳見主題）。
  3. 閒置閃爍利用終端機內建的 blink 屬性，就算 agy 沒有重新繪製，小星星仍會持續閃爍。
