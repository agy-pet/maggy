Maggy 🌋 zieht in deine agy-Statuszeile ein.

Ein animiertes agy-Pet und eine eigene Statuszeile für Antigravity CLI (agy). Maggys Logo-Animation tanzt, während agy arbeitet, stampft bei Tool-Aufrufen und nickt ein, wenn du kurz weg bist – direkt neben aktivem Modell, Kontext-Nutzung, 5-Stunden- & Wochen-Kontingentlimits mit Reset-Countdowns, Reasoning-Stufe und Git-Branch.

brew install agy-pet/tap/maggy && maggy setup

macOS oder Linux, Python 3, ein Truecolor-Terminal. Weitere Installationswege

Saisonale & eigene Themes

Standardmäßig kleidet auto Maggy an Feiertagen passend ein und wechselt am nächsten Tag zurück. Klicke auf eine Karte für die Live-Vorschau, fixiere ein Theme mit maggy theme <name> oder füge dein eigenes JSON-Theme hinzu.

Maggy für Antigravity CLI installieren

maggy setup trägt Maggy als statusLine in ~/.gemini/antigravity-cli/settings.json ein. Alle anderen Einstellungen bleiben unverändert, und die alte Datei wird als settings.json.bak gesichert.

  1. Mit Homebrew installieren
    brew install agy-pet/tap/maggy
  2. Maggy mit agy verbinden
    maggy setup
  3. Starte agy neu oder führe darin /statusline enable aus.

Aktualisieren mit brew upgrade maggy. Shell-Vervollständigungen für bash, zsh und fish sind enthalten.

  1. Starte das Installationsskript: Es klont nach ~/.maggy, verlinkt maggy nach ~/.local/bin und führt maggy setup aus.
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. Starte agy neu oder führe darin /statusline enable aus.

Optionen übergibst du per | bash -s -- --theme xmas --no-mood; spätere Updates laufen über maggy update.

  1. Repository klonen
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. Maggy mit agy verbinden
    ~/.maggy/bin/maggy setup
  3. Starte agy neu oder führe darin /statusline enable aus.

CLI-Befehle

Alles läuft über einen einzigen Befehl. Führe maggy help für die vollständige Liste aus.

maggy status
Zeigt, ob Maggy eingebunden ist, dein Theme, deine Einstellungen und eine Vorschau.
maggy preview idle
Spielt beliebige agent_state-Zustände direkt im Terminal ab, ohne den Agenten zu starten.
maggy statusline off
Blendet die Statuszeile aus, ohne sie zu entfernen. statusline on holt sie zurück.
maggy pet off
Blendet das Logo aus und behält die Metriken. motion off hält stattdessen eine feste Pose und side right setzt sie nach rechts. Alles unterstützt toggle.
maggy statusline hide git effort
Blendet einzelne Segmente aus: model, context, quota, workspace, git, effort. maggy statusline show blendet sie wieder ein.
maggy doctor
Prüft Python, Truecolor-Unterstützung, die Einstellungsdatei und die Renderzeit pro Frame.
maggy config
Zeigt ~/.config/maggy/config.json. Mit get, set oder reset anpassen.
maggy uninstall --purge
Entfernt den statusLine-Eintrag samt Konfiguration und Cache. Alle anderen agy-Einstellungen bleiben unberührt.

Eigenes Theme erstellen

Lege eine JSON-Datei in ~/.config/maggy/themes/ ab – der Dateiname wird zum Theme-Namen (z. B. paddy.json → maggy theme paddy). Färbe Bereiche oder Zellen um, tausche die Symbole, zeichne mit prop deine eigene Deko neben Maggy (wie den Baum oder die Laterne) oder starte mit base von einem eingebauten Theme. Setze dates für auto; mit maggy theme list siehst du alle Themes.

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

Häufige Fragen

Antworten rund um Installation, Anpassung und Fehlerbehebung der Maggy-Statuszeile für Antigravity CLI.

Wie zeige ich Nutzung, Kontingentlimits und Reset-Countdowns in der agy-Statuszeile an?

Installiere Maggy mit brew install agy-pet/tap/maggy && maggy setup und starte agy neu oder führe /statusline enable aus. Maggy bindet statusLine in ~/.gemini/antigravity-cli/settings.json ein und zeigt Modell, Kontext-Nutzung in %, farbcodierte 5-Stunden- und Wochen-Kontingentlimits mit Reset-Zeit und Countdown (über Aktualisierungen hinweg gecacht), Workspace, Git-Branch und Reasoning-Stufe an.

Warum erscheint die Statuszeile nach maggy setup nicht?

Starte agy neu oder gib in einer laufenden Sitzung /statusline enable ein. Falls weiterhin nichts erscheint, prüfe mit maggy doctor Python 3, Truecolor-Unterstützung und den statusLine-Eintrag in ~/.gemini/antigravity-cli/settings.json.

Verlangsamt Maggy agy oder sendet Telemetrie?

Nein. Die maggy-CLI läuft zu 100 % lokal nur mit der Python-3-Standardbibliothek und sendet keinerlei Telemetrie. agy ruft sie nur bei Statusänderungen auf (kein Hintergrund-Timer), und mit maggy doctor kannst du die Renderzeit jederzeit prüfen.

Kann ich das Maskottchen ausblenden oder Segmente anpassen?

Ja. Mit maggy pet off bleiben nur die Metriken, maggy motion off hält eine feste Pose und maggy side right verschiebt Maggy nach rechts. Einzelne Segmente blendest du mit maggy statusline hide (model, context, quota, workspace, git, effort) aus und mit maggy statusline show wieder ein.

Welche Plattformen und Terminals werden unterstützt?

Maggy läuft unter macOS und Linux (inkl. WSL) in jedem 24-Bit-Truecolor-Terminal wie Ghostty, Kitty, iTerm2, WezTerm, Alacritty, Warp oder dem integrierten VS-Code-Terminal und benötigt Python 3.

Wie funktioniert die agy-Pet-Animation in der Statuszeile?

Maggy zeichnet das Antigravity-Logo mit ausdrucksstarken Augen direkt im Terminal und spielt zustandsabhängige Animationen über agent_state ab – tanzend bei working, stampfend bei tool_use, spähend bei reviewing, blinkend bei idle und schlummernd nach 2 Minuten. Mit maggy preview working siehst du jede Animation vorab, und maggy motion off hält eine feste Pose.

  1. agy zeichnet die Statuszeile nur neu, wenn sich etwas ändert – nie per Timer. Im Leerlauf bleibt Maggy in einer Pose und nur ihre Sternchen blinken (über das Blink-Attribut des Terminals). Klicke erneut auf idle, um das nächste Neuzeichnen zu simulieren.
  2. auto wählt saisonale Looks automatisch nach Datum (siehe Themes).
  3. Das Blinken im Leerlauf nutzt das Blink-Attribut des Terminals – so leuchten die Sternchen weiter, auch wenn agy nichts neu zeichnet.
