A Maggy 🌋 mora na sua statusline do agy.

Um pet animado do agy e barra de status sob medida para a Antigravity CLI (agy). A animação da Maggy dança enquanto o agy trabalha, sapateia nas chamadas de ferramentas e tira um cochilo quando você se afasta — bem ao lado do modelo atual, uso de contexto, limites de cota de 5h e semanais com contagem de reset, nível de raciocínio e branch do git.

brew install agy-pet/tap/maggy && maggy setup

Temas sazonais e personalizados

Por padrão, auto veste a Maggy em datas festivas e volta ao normal no dia seguinte. Clique em um cartão para testar ao vivo, fixe um tema com maggy theme <name> ou adicione seu próprio tema em JSON.

Instale a Maggy para Antigravity CLI

maggy setup aponta statusLine em ~/.gemini/antigravity-cli/settings.json para a Maggy. Suas outras configurações permanecem intactas e o arquivo antigo é salvo como settings.json.bak.

  1. Instale via Homebrew
    brew install agy-pet/tap/maggy
  2. Conecte a Maggy ao agy
    maggy setup
  3. Reinicie o agy ou execute /statusline enable na sessão.

Atualize com brew upgrade maggy. Inclui autocompletar para bash, zsh e fish.

  1. Execute o instalador: ele clona para ~/.maggy, cria o link de maggy em ~/.local/bin e roda o maggy setup.
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. Reinicie o agy ou execute /statusline enable na sessão.

Passe opções com | bash -s -- --theme xmas --no-mood e atualize depois com maggy update.

  1. Clone o repositório
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. Conecte a Maggy ao agy
    ~/.maggy/bin/maggy setup
  3. Reinicie o agy ou execute /statusline enable na sessão.

Comandos CLI

Tudo passa por um único comando. Execute maggy help para ver a lista completa.

maggy status
Mostra se a Maggy está configurada, seu tema, suas opções e uma prévia ao vivo.
maggy preview idle
Reproduz qualquer agent_state no terminal sem precisar iniciar uma execução do agente.
maggy statusline off
Oculta a barra de status sem removê-la. statusline on a exibe novamente.
maggy pet off
Oculta o logotipo mantendo as métricas. motion off mantém uma pose estática e side right a move para a direita. Cada um aceita toggle.
maggy statusline hide git effort
Oculta os segmentos que quiser: model, context, quota, workspace, git, effort. maggy statusline show restaura.
maggy doctor
Verifica Python, suporte a truecolor, o arquivo de configuração e o tempo de renderização de um quadro.
maggy config
Mostra ~/.config/maggy/config.json. Use get, set ou reset para alterar.
maggy uninstall --purge
Remove a entrada statusLine, a configuração e o cache. Suas outras configurações do agy ficam intactas.

Crie seu próprio tema

Coloque um arquivo JSON em ~/.config/maggy/themes/ e o nome do arquivo vira o nome do tema (ex.: paddy.json → maggy theme paddy). Personalize cores por região ou célula, troque os brilhos, desenhe seu próprio prop ao lado da Maggy (como a árvore ou a lanterna) ou parta de um tema embutido com base. Defina dates para o auto ativar sozinho e rode maggy theme list para ver todos.

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

Perguntas frequentes

Dúvidas comuns sobre instalação, personalização e solução de problemas da barra de status Maggy para Antigravity CLI.

Como mostrar uso, limites de cota e contagem de reset na statusline do agy?

Instale a Maggy com brew install agy-pet/tap/maggy && maggy setup e reinicie o agy ou execute /statusline enable. A Maggy configura statusLine em ~/.gemini/antigravity-cli/settings.json e exibe o modelo atual, % de uso de contexto, barras coloridas de limite de cota de 5 horas e semanal com horário e contagem de reset (mantidos em cache entre atualizações), workspace, branch do git e nível de raciocínio.

Por que a barra de status não aparece após o maggy setup?

Reinicie o agy ou execute /statusline enable em uma sessão ativa. Se ainda não aparecer, rode maggy doctor para verificar o Python 3, o suporte a truecolor no terminal e a entrada statusLine em ~/.gemini/antigravity-cli/settings.json.

A Maggy deixa o agy mais lento ou envia telemetria?

Não. A CLI da maggy roda 100% localmente usando apenas a biblioteca padrão do Python 3 e envia zero telemetria. O agy só a chama quando o estado muda (sem timer em segundo plano) e você pode checar a velocidade de renderização com maggy doctor.

Posso ocultar a mascote ou escolher quais segmentos exibir?

Sim. Execute maggy pet off para manter apenas as métricas, maggy motion off para pose fixa ou maggy side right para mover a Maggy para a direita. Oculte segmentos com maggy statusline hide (model, context, quota, workspace, git, effort) e restaure com maggy statusline show.

Quais plataformas e terminais são suportados?

A Maggy funciona no macOS e Linux (incluindo WSL) em qualquer terminal truecolor (24 bits) como Ghostty, Kitty, iTerm2, WezTerm, Alacritty, Warp ou o terminal integrado do VS Code, e requer Python 3.

Como funciona a animação do pet do agy na statusline?

A Maggy desenha o logotipo da Antigravity com olhos expressivos diretamente no terminal e reproduz animações guiadas por agent_state — dançando em working, sapateando em tool_use, espiando em reviewing, brilhando em idle e cochilando após 2 minutos. Pré-visualize qualquer animação com maggy preview working ou fixe a pose com maggy motion off.

  1. O agy só redesenha a statusline quando algo muda, nunca por temporizador. Em repouso, a Maggy mantém uma pose e só os brilhos piscam (usando o atributo blink do terminal). Clique em idle de novo para simular o próximo redesenho.
  2. auto escolhe visuais sazonais pela data (veja Temas).
  3. A cintilação em repouso usa o atributo blink do terminal, mantendo as estrelinhas piscando mesmo quando o agy para de redesenhar.
