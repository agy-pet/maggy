Temas de temporada y propios

Por defecto, auto disfraza a Maggy en fechas señaladas y vuelve a la normalidad al día siguiente. Pulsa cualquier tarjeta para probarla en vivo, fija un tema con maggy theme <name> o crea el tuyo en JSON.

Instala Maggy para Antigravity CLI

maggy setup apunta statusLine en ~/.gemini/antigravity-cli/settings.json hacia Maggy. El resto de tus ajustes queda intacto y el archivo anterior se guarda como settings.json.bak.

  1. Instala el paquete con Homebrew
    brew install agy-pet/tap/maggy
  2. Conecta Maggy con agy
    maggy setup
  3. Reinicia agy o ejecuta /statusline enable dentro de agy.

Actualiza con brew upgrade maggy. Incluye autocompletado para bash, zsh y fish.

  1. Ejecuta el instalador: clona el repositorio en ~/.maggy, enlaza maggy en ~/.local/bin y ejecuta maggy setup.
    curl -fsSL https://agy-pet.github.io/install.sh | bash
  2. Reinicia agy o ejecuta /statusline enable dentro de agy.

Puedes pasar opciones con | bash -s -- --theme xmas --no-mood y actualizar más adelante con maggy update.

  1. Clona el repositorio
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. Conecta Maggy con agy
    ~/.maggy/bin/maggy setup
  3. Reinicia agy o ejecuta /statusline enable dentro de agy.

Comandos CLI

Todo pasa por un único comando. Ejecuta maggy help para ver la lista completa.

maggy status
Muestra si Maggy está configurada, tu tema y ajustes actuales, junto con una vista previa.
maggy preview idle
Reproduce cualquier agent_state en tu terminal sin iniciar un turno del agente.
maggy statusline off
Oculta la barra de estado sin borrar la configuración. statusline on la devuelve.
maggy pet off
Oculta el logotipo y deja solo las métricas. motion off la mantiene quieta y side right la pasa a la derecha. Todos admiten toggle.
maggy statusline hide git effort
Oculta los bloques que quieras: model, context, quota, workspace, git, effort. Con maggy statusline show vuelven a aparecer.
maggy doctor
Comprueba Python, el soporte truecolor, el archivo de configuración y la velocidad de renderizado.
maggy config
Muestra ~/.config/maggy/config.json. Usa get, set o reset para editarlo.
maggy uninstall --purge
Elimina la entrada statusLine, la configuración y la caché sin tocar tus demás ajustes de agy.

Crea tu propio tema

Guarda un archivo JSON en ~/.config/maggy/themes/ y su nombre será el del tema (p. ej. paddy.json → maggy theme paddy). Cambia colores por zona o celda, personaliza los destellos, dibuja tu propio prop junto a Maggy (como el árbol o el farolillo) o parte de un tema incluido con base. Define dates para que auto lo active solo y usa maggy theme list para ver todos los temas.

~/.config/maggy/themes/paddy.jsonschema
{
  "$schema": "https://agy-pet.github.io/theme.schema.json",
  "description": "St Patrick's Day",
  "colors": { "crown": "#1f9d55", "feet": [20, 120, 60] },
  "sparkles": { "✦": "☘", "·": "·" },
  "sparkle_color": "#a3e635",
  "prop": ["c c", "ccc", " s "],
  "prop_cells": {
    "c": { "bg": "#1f9d55" },
    "s": { "fg": "#3f6212", "glyphs": ["│"] }
  },
  "dates": ["03-17"]
}

Preguntas frecuentes

Dudas habituales sobre la instalación, personalización y solución de problemas de Maggy para Antigravity CLI.

¿Cómo muestro el uso, los límites de cuota y el tiempo de reinicio en la statusline de agy?

Instala Maggy con brew install agy-pet/tap/maggy && maggy setup y reinicia agy o ejecuta /statusline enable. Maggy se conecta a statusLine en ~/.gemini/antigravity-cli/settings.json y muestra el modelo activo, porcentaje de uso de contexto, barras de límite de cuota de 5 horas y semanales con hora y cuenta atrás de reinicio (en caché entre actualizaciones), espacio de trabajo, rama de git y nivel de razonamiento.

¿Por qué no aparece la barra de estado tras ejecutar maggy setup?

Reinicia agy o ejecuta /statusline enable dentro de una sesión activa. Si sigue sin aparecer, ejecuta maggy doctor para verificar Python 3, el soporte truecolor del terminal y la entrada statusLine en ~/.gemini/antigravity-cli/settings.json.

¿Maggy ralentiza agy o envía telemetría?

No. La CLI de maggy se ejecuta 100 % en local usando solo la biblioteca estándar de Python 3 y no envía telemetría. agy solo la invoca cuando cambia el estado (sin temporizadores en segundo plano) y puedes comprobar el tiempo de renderizado con maggy doctor.

¿Puedo ocultar la mascota o elegir qué segmentos mostrar?

Sí. Ejecuta maggy pet off para ver solo las métricas, maggy motion off para una pose fija o maggy side right para mover a Maggy a la derecha. Oculta segmentos con maggy statusline hide (model, context, quota, workspace, git, effort) y restáuralos con maggy statusline show.

¿Qué plataformas y terminales son compatibles?

Maggy funciona en macOS y Linux (incluido WSL) en cualquier terminal truecolor (24 bits) como Ghostty, Kitty, iTerm2, WezTerm, Alacritty, Warp o el terminal integrado de VS Code, y requiere Python 3.

¿Cómo funciona la animación de la mascota de agy en la statusline?

Maggy dibuja el logotipo de Antigravity con ojos expresivos directamente en tu terminal y reproduce animaciones según agent_state: baila en working, zapatea en tool_use, se inclina en reviewing, parpadea en idle y duerme tras 2 minutos. Previsualiza cualquier animación con maggy preview working o fíjala con maggy motion off.

  1. agy solo actualiza la statusline cuando algo cambia, nunca con un temporizador. En reposo, Maggy mantiene una pose y solo parpadean sus destellos (mediante el atributo blink de la terminal). Haz clic de nuevo en idle para simular la siguiente actualización.
  2. auto elige el tema estacional según la fecha (ver Temas).
  3. El parpadeo en reposo usa el atributo blink de la terminal, así que los destellos siguen activos aunque agy deje de actualizar la pantalla.
