Maggy lives in your agy statusline.

An animated terminal pet and custom Antigravity CLI (agy) statusline. Maggy dances while agy works, stomps through tool calls, and dozes off when you step away — right beside your live model, context window, quota usage bars, reasoning effort, and git branch.

brew install agy-pet/tap/maggy && maggy setup

macOS or Linux, Python 3, a truecolor terminal. Other ways to install

Customize your agy statusline

This is the statusline agy draws under your prompt. Maggy sits to the left of your model, context usage, color-coded quota bars, workspace, and git branch — every frame is the same width, so nothing beside her ever shifts. Change a setting below to see the command that does it.

agy~/code/my-app
> refactor the auth middleware and add tests
maggy name --reset
Theme
maggy theme auto
maggy mood on
maggy blink on

auto switches to the Xmas look by itself on December 25: Santa hat, falling snow, lights on the arch and a little tree. Idle twinkle uses the terminal's blink attribute, so sparkles keep moving even when agy stops redrawing.

Install Maggy for Antigravity CLI

maggy setup points statusLine in ~/.gemini/antigravity-cli/settings.json at Maggy. Your other settings stay as they are, and the old file is saved as settings.json.bak.

  1. Install the formula
    brew install agy-pet/tap/maggy
  2. Hook Maggy into agy
    maggy setup
  3. Restart agy, or run /statusline enable inside it.

Upgrade with brew upgrade maggy. Shell completions for bash, zsh and fish come with it.

  1. Run the installer. It clones to ~/.maggy, links maggy into ~/.local/bin and runs maggy setup.
    curl -fsSL https://raw.githubusercontent.com/agy-pet/maggy/master/install.sh | bash
  2. Restart agy, or run /statusline enable inside it.

Pass setup options with | bash -s -- --theme xmas --no-mood. Update later with maggy update.

  1. Clone the repo
    git clone https://github.com/agy-pet/maggy.git ~/.maggy
  2. Hook Maggy into agy
    ~/.maggy/bin/maggy setup
  3. Restart agy, or run /statusline enable inside it.

CLI commands

Everything goes through one command. Run maggy help for the full list.

maggy status
Shows whether Maggy is hooked up, your theme and settings, and a sample of her.
maggy preview idle
Plays any agent_state in your terminal without starting an agent turn.
maggy statusline off
Hides the statusline without removing it. statusline on brings it back.
maggy pet off
Hides the logo and keeps the metrics. motion off holds a still pose instead, and side right moves her to the right. Each takes toggle.
maggy statusline hide git effort
Leaves segments out: model, context, quota, workspace, git, effort. maggy statusline show brings them back.
maggy doctor
Checks Python, truecolor support, the settings file, and how fast a frame renders.
maggy config
Shows ~/.config/maggy/config.json. Use get, set or reset to change it.
maggy uninstall --purge
Removes the statusLine entry, config and cache. Your other agy settings stay.
